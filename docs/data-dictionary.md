# Diccionario de datos — Fase 1

`Setup.gs` crea 48 hojas lógicas del MVP. Todas usan identificadores propios; nunca se usa el número de fila como relación.

## Dominios principales
- Identidad: `USERS`, `USER_ROLES`, `CUSTOMER_PROFILES`, `ADDRESSES`.
- Comercios: `MERCHANTS`, `MERCHANT_USERS`, `STORE_LOCATIONS`, `BUSINESS_HOURS`, `MERCHANT_DOCUMENTS`.
- Catálogo: `CATALOG_CATEGORIES`, `PRODUCTS`, `PRODUCT_VARIANTS`, `MODIFIER_GROUPS`, `MODIFIER_OPTIONS`, `PRODUCT_MODIFIER_GROUPS`, `INVENTORY`, `PRODUCT_IMAGES`.
- Pedidos: `ORDERS`, `ORDER_ITEMS`, `ORDER_ITEM_MODIFIERS`, `ORDER_STATUS_EVENTS`.
- Delivery: `DELIVERY_JOBS`, `DELIVERY_OFFERS`, `DRIVERS`, `VEHICLES`, `DRIVER_DOCUMENTS`, `DRIVER_LOCATIONS_CURRENT`.
- Finanzas: `PAYMENTS`, `PAYMENT_EVENTS`, `REFUNDS`, `COMMISSION_RULES`, `MERCHANT_LEDGER`, `MERCHANT_SETTLEMENTS`, `DRIVER_LEDGER`, `DRIVER_SETTLEMENTS`, `CASH_COLLECTIONS`, `CASHBACK_LEDGER`.
- Marketing: `COUPONS`, `COUPON_REDEMPTIONS`.
- Operación: `DELIVERY_ZONES`, `DELIVERY_RATE_RULES`, `CUSTOMER_TRUST_RULES`, `REVIEWS`, `SUPPORT_TICKETS`, `NOTIFICATIONS`, `WEBHOOK_EVENTS`, `AUDIT_LOG`, `SYSTEM_CONFIG`.

Los encabezados exactos están definidos en `apps-script/Setup.gs` para mantener una sola fuente de verdad en esta etapa.
