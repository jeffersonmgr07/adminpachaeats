# Notas para manual de usuario

## Cliente
La pantalla de inicio permite elegir categorías, revisar comercios, tiempos estimados, costo de delivery y promociones.

## Comercio
El panel prioriza pedidos activos, ventas del día, tiempo promedio y estados de preparación.

## Repartidor
La pantalla prioriza el estado conectado, ganancias y la aceptación de una oferta con información resumida de origen/destino.

## Superadministrador
El dashboard resume GMV, pedidos, comercios, repartidores y pedidos activos.
